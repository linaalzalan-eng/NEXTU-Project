# إعادة التصميم — المرحلة 1: الهوية وأساس الثيمات

## 1. النتيجة
نُفّذت المرحلة الأولى المعتمدة فقط: شعار U الصاعد، ألوان الهوية، وثيمات فاتح/داكن/النظام. بقية إعادة تصميم المكوّنات والصفحات تنتظر موافقة مستقلة.

## 2. الملفات
- src/index.css وdocs/DESIGN_SYSTEM.md: الألوان والأحجام والزوايا والأسطح في الثيمين.
- src/lib/theme/: المزوّد والحالة والخطاف والاختبارات.
- index.html: تطبيق الثيم قبل ظهور React.
- ThemeSwitch وBrandMark ضمن src/components/layout، وربطهما بالـlayouts الحالية وAppProviders.
- public/brand/: الشعار الكامل والأيقونة للفـاتح والداكن، مع favicon.svg.
- ملفات الترجمة ar/en: اسم NextU وخيارات المظهر.

## 3. التقنية
CSS variables توصل الثيم لكل المكوّنات والرسوم الحالية. React Context يوفّر التفضيل، وuseSyncExternalStore يتابع إعداد الجهاز. الاختيار native select قابل للكيبورد وقارئ الشاشة، دون مكتبات جديدة.

## 4. كيف يرتبط الكود
`ThemeProvider` يحيط بالمزوّدات الحالية؛ لا يعيد تركيب AuthProvider أو TasksProvider عند تبديل اللون. `useTheme()` يعيد preference وresolvedTheme وsetTheme. `data-theme=dark` يبدّل قيم الألوان نفسها التي تستخدمها الواجهات.

## 5. تدفق الاستخدام
اختر المظهر من الشريط الجانبي أو أيقونة المظهر بجانب اللغة على الهاتف وصفحات الحساب. يُحفظ في nextu.theme بشكل مستقل عن اللغة. خيار النظام يتابع الجهاز، والاختيار الصريح يتقدّم عليه. لا يحتاج تحديثًا أو إعادة دخول.

## 6. القرارات
D-32: إبقاء IBM Plex Sans Arabic وواجهات الخدمات، مع ألوان مستقلة للنص فوق الأزرار والأسطح المعكوسة. تصحيح ألوان النص في زر مشترك وcheckbox ضروري للتباين فقط؛ إعادة تنسيقها الكاملة في المرحلة الثانية. لا صفحة إعدادات جديدة ولا تغيير قاعدة بيانات.

## 7. الفحوص
- 379/379 اختبارًا في 43 ملفًا نجحت، منها 16 اختبارًا جديدًا للثيم والتهيئة والاختيار باللغتين. جرى إثبات فشل الاستيراد قبل إنشاء تنفيذ الثيم ثم نجاحه.
- Lint وBuild ناجحان. أول تشغيل متزامن مع البناء تعثّر بمهلة استيراد Analytics؛ الجولة الكاملة بعاملين نجحت دون تعديل المهلة أو التأكيدات.
- Chrome: 24/24 حالة لصفحات Dashboard/Tasks/Analytics × فاتح/داكن × عربي/إنجليزي × 360/1280.
- تأكدنا أن الداكن يطبّق حتى مع حظر ملفات React، وأن System يتابع إعداد الجهاز وأن التفضيل يبقى بعد التحديث.
- الدخول الحقيقي وحفظ الجلسة وفتح صفحة محمية والخروج بعد تحديث الصفحة نجحت؛ بيانات المهام لم تتغيّر.
- تباين النص/السطح والأزرار الأساسية فُحص في المتصفح: أقل زوج 5.07:1، وجميع الأزواج المفحوصة أعلى من 4.5:1.

## 8. ملاحظات
اللّقطات محفوظة محليًا في artifacts/redesign-phase1. اختبار الأحجام الحالي يخص الصفحات الأساسية؛ الرسوم ذات البيانات والنماذج المعاد تصميمها والحوارات لها مراجعة أشمل في مراحلها. ملف الشعار الكامل يستخدم نص SVG قابلًا للتحرير مع خط النظام كبديل، والأيقونة مسارات SVG فقط.

افتح التطبيق وبدّل المظهر، ثم حدّث الصفحة وبدّل اللغة. جرّب النظام مع تغيير ثيم جهازك. سؤال: ما الفرق بين التفضيل System واللون المحسوب Dark؟ ولماذا يحتاج النص فوق الزر لونًا مستقلًا عن النص العادي؟

المراجعة المستقلة للمرحلة الأولى لم تجد ملاحظات حرجة أو مهمة. ملفات SVG الخمسة سليمة، ومفاتيح الترجمة العربية والإنجليزية متطابقة. بانتظار اعتمادك قبل المرحلة الثانية.
